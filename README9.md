## Aim
To develop a simple chatbot using a pre-trained Large Language Model (LLM) based on Transformer architecture.

## Software Requirements
- Python
- Google Colab
- Hugging Face Transformers
- PyTorch
- Gradio
- SentencePiece

## Objectives
1. Understand the working of Transformer-based language models.
2. Load a pre-trained LLM using Hugging Face.
3. Generate responses from user prompts.
4. Develop an interactive chatbot using Gradio.
5. Deploy the chatbot using Hugging Face Spaces.

## Procedure
1. Install the required Python libraries.
2. Load the pre-trained `google/flan-t5-small` model and tokenizer.
3. Provide user prompts to the model.
4. Generate responses using the `generate()` function.
5. Implement chatbot functionality using Python.
6. Create an interactive chatbot interface using Gradio.
7. Test the chatbot with different questions.
8. Create a requirements file and deploy the chatbot using Hugging Face Spaces.

## Implementation
The experiment is divided into four parts:

- **Part A:** Loading the pre-trained Transformer model and generating responses.
- **Part B:** Implementing chatbot response generation.
- **Part C:** Creating an interactive chatbot interface using Gradio.
- **Part D:** Testing the chatbot and preparing files for deployment.

## Output
The chatbot successfully accepts user prompts and generates responses using the pre-trained FLAN-T5 model. An interactive interface is created using Gradio.

## Result
Thus, a Transformer-based LLM chatbot was successfully developed, tested, and prepared for cloud deployment using Hugging Face Spaces.
